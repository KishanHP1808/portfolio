## 💻 Run Locally

```bash
git clone https://github.com/KishanHP1808/portfolio.git
cd portfolio
npm install
npm run dev
```

Open the local URL printed in your terminal by Vite.

For a production build:

```bash
npm run build
npm start
```

Some integrations may require environment variables. Check `.env.example` and configure the values needed for your local setup. Never commit API keys, passwords, or other secrets.
